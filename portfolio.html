Corpus
CONSENT-FIRST AI DATA PLATFORM
The idea

Corpus helps people license the value in their own AI chats. It collects only with upfront consent, sanitizes on-device, and lets contributors approve what is shared before any dataset release.

Product surface

Chrome extension, encrypted Tauri desktop app, Next.js web dashboard, and Fastify API — all organized around a review queue and a clear consent trail.

Nothing leaves the computer until it has been sanitized and approved.
Why it matters

Privacy projections, secret and PII redaction, device pairing, and revocable consent make data provenance a product feature instead of an afterthought.

HUMAN-IN-THE-LOOP JOB APPLICATION ASSISTANT
The idea

A Chrome side-panel that reads application forms, maps high-confidence facts from a local profile, and drafts answers while keeping the applicant in control.

Safety by design

It never submits an application — the final decision stays human.

React · Vite · TypeScript · Manifest V3 · IndexedDB · local Codex bridge
